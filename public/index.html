CIGO live swap

Live CIGO / BSC-USD (USDT) pool swap on BNB Smart Chain. Rabby Wallet is recommended.

Plain interface: contracts, balances, liquidity, trade steps, risks, and status. No mascot theater. No hidden interface fee.
What fees apply? This interface does not add a trade.cosigo.io fee and does not use a wallet swap aggregator. A CIGO pool swap may include CIGO contract tax, the normal PancakeSwap V2 pool trading fee, BNB network gas, and slippage from pool movement. Review the Rabby confirmation before signing.
Public swap limit: this interface limits each swap to approximately $300. This protects against accidental large approvals, pool movement, and user error.
