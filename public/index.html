New exact-approval swaps normally use two blockchain transactions: approval first, then swap. If allowance is already verified, only the swap confirmation is needed.

Live swap notice: This interface connects directly to the CIGO / BSC-USD PancakeSwap V2 pool. It does not add a trade.cosigo.io interface fee and does not use a wallet swap aggregator. A live swap may include CIGO contract tax, PancakeSwap V2 pool fee, BNB network gas, slippage, and current pool movement. Each public swap is limited to approximately $500 to reduce accidental large approvals, pool impact, and user error. Review the Rabby confirmation before signing. The reviewed/manual request flow remains available at discount desk.
