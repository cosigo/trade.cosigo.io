Trade interface design

The official CIGO trade interface uses a direct PancakeSwap V2 route, shows wallet status and pool information, discloses fee and slippage considerations, and requires normal wallet confirmation before any transaction is signed. It does not use hidden wallet aggregation, hidden routing, automatic token movement, or forced approvals.
