CIGO / BSC-USD route review

Official swap route and DEX Screener widget note.

This page separates the working official CIGO swap path from third-party chart and embedded trade widgets. It helps users review wallet confirmations before signing.

Official swap route

Use trade.cosigo.io for swaps.

The official CIGO swap interface is designed to route directly through PancakeSwap V2 and does not use a wallet swap aggregator.

Wallet confirmation rule

  • Use trade.cosigo.io for the official live swap path.
  • In Rabby, review the spender before approving.
  • For official direct swaps, the expected spender is PancakeSwap V2 Router 0x10ED43...56024E.
  • Cancel if a third-party page shows an unfamiliar spender, wrong token, wrong chain, unlimited approval, or unexpected route.
  • Treat DEX Screener as chart/reference only until its Buy/Sell widget routing is corrected or hidden.
