1b) Manual import — Rabby Wallet recommended

Advanced users can import CIGO manually into Rabby Wallet, then connect to trade.cosigo.io from Rabby or another compatible wallet browser.

  1. Open Rabby Wallet.
  2. Switch to BNB Smart Chain.
  3. Choose Add token or Import token.
  4. Paste the official CIGO contract address.
  5. Confirm that Rabby fills CIGO with 18 decimals.
  6. Import the token.
  7. Open trade.cosigo.io.
  8. Connect wallet, choose from / to / amount, get quote, request swap, verify, then send request.
CIGO remains recoverable as long as your wallet seed phrase is written down, protected, and never shared. If needed, you can restore your wallet and re-import the token later. Never enter your seed phrase into any website.
