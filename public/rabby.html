Rabby Wallet / CIGO

Use Rabby carefully with the official CIGO swap page.

This guide is for importing CIGO, opening the official trade interface, and checking approval and swap confirmations before signing.

Official CIGO contract

BNB Smart Chain CIGO token:

0x3a38e963f524E0dDFB75dFa1752b4Cd1364F5560

Only use this address for the current BNB Chain CIGO token.

1. Open Rabby on BNB Chain

Open Rabby Wallet and make sure the selected network is BNB Smart Chain.

If Rabby is on Ethereum or another chain, switch to BNB Smart Chain before importing or trading CIGO.

2. Import CIGO manually

In Rabby, import a custom token on BNB Smart Chain.

Paste the CIGO contract address:

0x3a38e963f524E0dDFB75dFa1752b4Cd1364F5560

Rabby should identify the token symbol as CIGO with 18 decimals.

3. Open the official swap page

Use the official CIGO swap interface:

https://trade.cosigo.io/

The page uses a direct PancakeSwap V2 route. It does not use hidden wallet aggregation or automatic token movement.

4. Approve exact input first

For BSC-USD (USDT) to CIGO, Rabby may ask for an approval before the swap.

Check that the token being approved is BSC-USD / USDT, the amount is close to the exact amount entered, and the spender is the PancakeSwap V2 router:

0x10ED43C718714eb63d5aA57B78B54704E256024E

Cancel if the approval looks unlimited, unrelated, or confusing.

5. Review the swap confirmation

After approval, Rabby should show the swap transaction.

Review the from token, to token, amount, slippage, minimum received, gas fee, and route before signing.

The wallet confirmation is the final live execution review. Do not sign if the confirmation does not match what you intended.

Safety notes

Never sign a transaction you do not understand.

Never approve unlimited token spending unless you intentionally choose to accept that risk.

Do not trust direct messages, fake support accounts, or unofficial links.
